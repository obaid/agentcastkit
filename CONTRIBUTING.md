# Contributing to AgentCastKit

Thank you for helping make agent-driven recording safer and more useful.

## Development

AgentCastKit currently requires an Apple silicon Mac with macOS 15 or newer, Xcode command-line tools, and Node.js 22 or newer.

```bash
npm install
npm run check
```

Keep changes focused, add or update tests for behavior changes, and preserve the explicit user-confirmation boundary around permission prompts and recording. Do not add provider credentials, generated media, local `.env` files, signing keys, or notarization credentials to the repository.

## Pull requests

Explain the user-facing outcome and privacy implications. Include the verification commands you ran. By submitting a contribution, you agree that it is licensed under Apache License 2.0.
